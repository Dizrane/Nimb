# Ретранслятор отчётов Nimb

Маленький Cloudflare Worker (бесплатный тариф). Приложение отправляет ему отчёт о проблеме, он пересылает его
в ваш Telegram файлом `nimb-report-<номер>.txt` и 90 дней хранит у себя, чтобы их можно было забрать все сразу одним файлом. Токен бота и ваш чат хранятся только в секретах Worker, в приложении их нет.

## Что нужно один раз

1. Бесплатный аккаунт на [cloudflare.com](https://dash.cloudflare.com/sign-up).
2. Бот в Telegram: откройте @BotFather, команда `/newbot`, сохраните токен.
3. Node.js (<https://nodejs.org>).

## Запуск

```
./deploy.sh
```

Скрипт войдёт в Cloudflare, спросит токен бота, найдёт ваш чат, опубликует Worker, положит токен и чат в секреты и
отправит проверочный отчёт. В конце напечатает адрес вида `https://nimb-report.<имя>.workers.dev/`:
его нужно вписать в `Sources/Nimb/Report/ReportSender.swift` (`ReportConfig.endpoint`).
`wrangler.toml` скрипт собирает сам из `wrangler.template.toml` (там id вашего хранилища отчётов), в репозиторий он не попадает.

## Забрать все отчёты одним файлом

В конце `deploy.sh` печатает ссылку вида `https://nimb-report.<имя>.workers.dev/export?key=...`. Откройте её в браузере: скачается
`nimb-reports-<дата>.txt` со списком всех отчётов сверху и полным текстом каждого ниже, старые выше. Этот файл можно передать на разбор.
`&clear=1` в конце ссылки удалит выгруженные отчёты (чтобы в следующий раз скачать только новые). Ключ в ссылке секретный: сменить его
можно командой `npx wrangler secret put EXPORT_KEY`.

## Что защищает от мусора

- принимает только JSON нужной формы, не больше 100 КБ;
- не больше 5 отчётов в минуту с одного адреса (Cloudflare Rate Limiting);
- адреса отправителя не пересылаются и не сохраняются.

## Проверка без аккаунта

```
npm install
npm test            # проверки кода Worker на подставном Telegram
npx wrangler dev --local
```

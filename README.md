# Nimb

Smart DNS для macOS одной кнопкой.

[Скачать](../../releases/latest) · [Новости и релизы в Telegram: @NimbProject](https://t.me/NimbProject)

## Для чего

Многие нейросети и другие сервисы (ChatGPT, Claude, Gemini, Grok, ElevenLabs) не открываются из-за региона. Бесплатные Smart DNS-сервисы это решают, но настраивать DNS вручную в системных настройках неудобно, а какой из сервисов работает именно у вас, заранее не знаешь.

Nimb включает Smart DNS (GeoHide EU, RU, US или Comss.one) на всех сетевых подключениях Mac одной кнопкой, а при выключении возвращает DNS от роутера или провайдера. Это не VPN: через сервис идут только DNS-запросы, остальной трафик идёт напрямую.

## Возможности

- **Одна кнопка.** Включить и выключить DNS на Wi-Fi, Ethernet и других подключениях сразу.
- **Проверка сервисов.** Покажет, какой из четырёх DNS сейчас работает у вас с ChatGPT, Claude, Gemini, Grok и ElevenLabs, и подскажет лучший. Системный DNS при проверке не меняется.
- **Четыре сервиса:** GeoHide (EU), Comss.one, GeoHide (RU), GeoHide (US). На глобусе виден регион выбранного сервиса.
- **Без пароля (по желанию).** В настройках можно разрешить переключать DNS без пароля, см. ниже.
- **Обновление в одно нажатие** и **полное удаление** прямо из приложения.
- Открытый код, лицензия MIT, без аккаунтов и телеметрии.

## Установка

1. Скачайте `Nimb-<версия>.zip` из [Releases](../../releases/latest) и распакуйте его.
2. Перетащите `Nimb.app` в «Программы» и откройте. Приложение без подписи Apple Developer, поэтому при первом запуске: правый клик → **Открыть** → **Открыть** (или Системные настройки → Конфиденциальность и безопасность → **Всё равно открыть**).
3. Не уверены, какой сервис работает у вас, нажмите **Проверить сервисы**. Затем выберите сервис (по умолчанию GeoHide (EU)) и нажмите большую кнопку. macOS попросит пароль администратора или Touch ID: без этого DNS менять нельзя.
4. Нажмите ещё раз, чтобы вернуть автоматический DNS.

Нужна macOS 13 или новее, работает на Apple Silicon и Intel.

## Сервисы

| Сервис | Адреса |
|---|---|
| GeoHide (EU) (по умолчанию) | `143.20.64.192`, `45.13.237.213` |
| Comss.one | `83.220.169.155`, `212.109.195.93` |
| GeoHide (RU) | `159.194.200.33`, `193.233.112.67` |
| GeoHide (US) | `192.255.159.241`, `192.255.159.240` |

Бесплатные сервисы то работают, то нет, и у разных людей по-разному. Поэтому в приложении есть проверка: для каждого DNS она спрашивает адреса сайтов и API ChatGPT, Claude, Gemini, Grok и ElevenLabs и обращается к каждому адресу по HTTPS. Результат показан в строке сервиса: ✓ работает, ⚠ нестабильно, ✗ не отвечает, ⊘ закрыт, а справа время ответа. Кнопка **Выбрать лучший** включает тот DNS, через который работает больше сервисов.

Просто «страница открылась» за успех не считается. Проверка различает ответ, которым сервис впускает посетителя, и отказ: «недоступно в вашем регионе», ответ 403 у API, перенаправление на страницу ограничений (например, Google «подозрительный трафик» или справка ElevenLabs о странах). Такой адрес показан как отказ, а сервис с хотя бы одним отказом получает ⚠, потому что часть заходов попадёт именно на него. Подробности по адресам видны, если навести на значок ⓘ в строке сервиса.

- **API** спрашивается без ключа. Сервис, который впустил запрос, отвечает «нужен ключ» (401), а закрытый по региону или адресу отвечает отказом. Это самый надёжный признак.
- **Сайты** за защитой Cloudflare (ChatGPT, Claude) отвечают проверкой для браузера, поэтому по ним видно только то, что адрес доступен. У сайтов без неё (Gemini, ElevenLabs, Grok) отказ по региону или адресу виден и в ответе сайта.
- Проверка не открывает приложения и не входит в аккаунт, поэтому отказ, который сервис показывает уже после входа (например, по стране аккаунта), она не увидит.

## Настройки

Шестерёнка в правом верхнем углу. Там можно дать или забрать разрешения Nimb и удалить приложение.

**Смена DNS без пароля.** По умолчанию macOS спрашивает пароль при каждом переключении. Если это мешает, разрешите Nimb один раз: он добавит правило sudo, которое позволяет вашей учётной записи без пароля только переключать DNS между сервисами Nimb и автоматическим и сбрасывать DNS-кэш. Произвольный DNS задать по этому правилу нельзя.

Цена: любая программа, запущенная от вашего имени, сможет так же переключить DNS между сервисами Nimb (а они видят ваши DNS-запросы) или вернуть автоматический. Ограничить правило именно приложением Nimb система не позволяет. Если появится новое сетевое подключение, нажмите «Добавить подключения» в настройках. Забрать разрешение можно кнопкой «Забрать» или командой `sudo rm /etc/sudoers.d/nimb`.

**Удалить Nimb.** Возвращает DNS к автоматическому (только там, где стоит сервис Nimb: заданный вами вручную не трогается), убирает правило «без пароля», закрывает приложение и удаляет его вместе с настройками и кэшем.

## Обновление

При запуске Nimb один раз проверяет GitHub, а кнопка внизу окна проверяет в любой момент. Если вышла новая версия, нажмите **Обновить**: приложение скачает релиз, сверит SHA-256 с указанным в описании, проверит подпись и перезапустится. Хэш лежит в том же релизе, что и файл: это защита от повреждённой загрузки, но не от взлома самого репозитория. Заменить приложение можно, только если оно лежит в папке, куда у вас есть доступ на запись (например, «Программы»).

## Как это работает

Приложение вызывает стандартные команды macOS и больше ничего не делает:

```sh
networksetup -setdnsservers "<сервис>" 83.220.169.155 212.109.195.93   # включить
networksetup -setdnsservers "<сервис>" Empty                           # выключить
dscacheutil -flushcache; killall -HUP mDNSResponder                    # сбросить кэш
```

DNS меняется на всех включённых сетевых сервисах с физическим адаптером (Wi-Fi, Ethernet). VPN-подключения не затрагиваются.

## Важно

- Проект не связан с Comss.one и GeoHide. Это бесплатные сервисы, доступ через них может пропасть в любой момент: если сайт не открывается, переключитесь на другой.
- Если на Mac включён VPN, DNS-профиль (Системные настройки → Сеть → VPN и фильтры → «Фильтры и прокси») или локальный DNS-прокси, они могут использовать свой DNS и перекрывать настройки приложения. В этом случае Nimb покажет предупреждение под списком сервисов.
- Пользуйтесь сервисами по их правилам. Всё, что вы делаете с программой, вы делаете на свой риск.

## Сборка из исходников

Нужны Xcode или Command Line Tools (Swift 5.9+), macOS 13+.

```sh
./scripts/build_app.sh
open build/Nimb.app
```

Идея и принцип работы взяты у [hb-ai-xbox-dns](https://github.com/neiroseti-ai/hb-ai-xbox-dns) для Windows, код написан с нуля на Swift/SwiftUI. Название от слова «нимб».

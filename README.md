# Nimb

> Раньше проект назывался RDNS. Если у вас стоит старая версия (0.1.1–0.2.2), нажмите «Обновить» внизу окна: она поставит Nimb, а в релизе остаётся копия `RDNS-<версия>.zip` для таких установок. Версию 0.1.0 нужно заменить вручную.

Smart DNS одной кнопкой для macOS. Включает DNS-сервис (GeoHide (EU), Comss.one, GeoHide (RU), GeoHide (US)) на всех сетевых подключениях Mac, а при выключении возвращает DNS от роутера или провайдера. Это не VPN: через сервис идут только DNS-запросы, остальной трафик идёт напрямую.

Название — от слова «нимб». Идея и принцип работы взяты у [hb-ai-xbox-dns](https://github.com/neiroseti-ai/hb-ai-xbox-dns) для Windows. Код написан с нуля на Swift/SwiftUI.

## Как пользоваться

1. Соберите приложение (см. ниже) или скачайте `Nimb-<версия>.zip` из [Releases](../../releases) и распакуйте его.
2. Перетащите `Nimb.app` в «Программы» и откройте его. Приложение без подписи Apple Developer, поэтому при первом запуске: правый клик → **Открыть** → **Открыть** (или Системные настройки → Конфиденциальность и безопасность → **Всё равно открыть**).
3. Не уверены, какой сервис работает у вас, нажмите **Проверить сервисы**. Затем выберите сервис (по умолчанию GeoHide (EU)) и нажмите большую кнопку. macOS запросит пароль администратора (или Touch ID) при каждом переключении; чтобы этого не было, см. «Переключение без пароля» ниже.
4. Нажмите ещё раз, чтобы вернуть автоматический DNS.

## Оформление

Фон приложения чёрно-белый, а цвет оставлен только для статусов, чтобы взгляд сразу видел главное. Пока DNS выключен, вы «в облаках»: серое небо с плывущими облаками и одна крупная белая кнопка. Нимба в этом состоянии нет. Как только DNS включён, облака уходят вниз, остаётся чёрный космос со звёздами, кнопка уменьшается до значка под появившейся планетой, а над планетой поднимается нимб (как венец): светится вся лента, по ней медленно дрейфуют искры и тонкие дуги. Нижняя, дальняя половина кольца уходит за планету, верхняя, ближняя, идёт поверх неё. На планете зелёным подсвечен регион выбранного сервиса: Европа для GeoHide (EU), Россия для GeoHide (RU) и Comss.one, США для GeoHide (US); при смене сервиса планета плавно поворачивается к нему. Спутник один раз прилетает на своё место и шлёт сигнал в город региона (Франкфурт, Москва, Буффало). Во время проверки сервисов при выключенном DNS от кнопки расходятся кольца, при включённом искры ускоряются. Статусы показаны приглушённым цветом и формой: зелёный ✓ работает, янтарный ⚠ нестабильно, красный ✗ не отвечает; рекомендуемый сервис отмечен янтарным ромбиком и подписью «Рекомендуем». Оформление строгое: засечный заголовок (системный New York), тонкие линии вместо заливок и свечений, спокойные плавные движения без пружин. Анимации ставятся на паузу, когда окно не на переднем плане, и отключаются при включённом «Уменьшении движения».

Регион сервиса определён по месту его DNS-серверов (проверено по адресам): серверы Comss.one стоят в Москве, при этом его выходные узлы к нейросетям находятся в Амстердаме.

Береговые линии и контуры регионов взяты из [Natural Earth](https://www.naturalearthdata.com/) (общественное достояние, масштаб 110m) и лежат в `Resources/world.json`. Пересобрать файл можно так: скачайте `ne_110m_land.geojson` и `ne_110m_admin_0_countries.geojson` из [репозитория Natural Earth](https://github.com/nvkelso/natural-earth-vector/tree/master/geojson) и запустите

```sh
python3 -I scripts/make_world.py ne_110m_land.geojson ne_110m_admin_0_countries.geojson Resources/world.json
```

Нимб нарисован кодом `Sources/Nimb/HaloRenderer.swift` по фотографии длинной выдержки: толстая лента, двойная линия, сияние, лучи. Этим же кодом рисуются обе иконки: `Resources/AppIcon.icns` (нимб на чёрном; иконка файла, Finder и Launchpad) и `Resources/AppIconActive.icns` (нимб над планетой). Пока DNS включён и приложение запущено, в Dock показывается вторая; после выхода из приложения Dock возвращает первую. Перерисовать иконки: `scripts/make_icons.sh`.

## Сервисы

| Сервис | Адреса |
|---|---|
| GeoHide (EU) (по умолчанию) | `143.20.64.192`, `45.13.237.213` |
| Comss.one | `83.220.169.155`, `212.109.195.93` |
| GeoHide (RU) | `159.194.200.33`, `193.233.112.67` |
| GeoHide (US) | `192.255.159.241`, `192.255.159.240` |

Бесплатные сервисы то работают, то нет, и у разных людей по-разному. Поэтому в приложении есть проверка.

## Проверка сервисов

Кнопка **Проверить сервисы** для каждого DNS спрашивает его напрямую об адресах сайтов и API ChatGPT, Claude, Gemini и ElevenLabs, затем отправляет HTTPS-запрос на **каждый** адрес из ответа. Результат показан прямо в строке сервиса: под названием перечислены ChatGPT, Claude, Gemini и ElevenLabs с отметкой ✓ (работает), ⚠ (нестабильно) или ✗ (не отвечает), справа время до первого байта. Системный DNS при проверке не меняется, пароль не нужен.

- Сервис считается работающим, если ответило не менее 75% запросов к его сайту и API вместе. Один неработающий адрес в пуле из пяти его не отключает. Если не ответил ни один запрос, это ✗.
- Если навести на строку, видны подробности по сервисам и адреса пула, которые не отвечают совсем.
- **Выбрать лучший**: побеждает DNS, через который работает больше сервисов; при равенстве выигрывает заметно более быстрый (разница меньше 0,1 с считается шумом), иначе остаётся первый в списке. Кнопка работает как нажатие на сервис в списке: если DNS уже включён, он переключится на выбранный (потребуется пароль).
- Проверка показывает, отвечают ли сайты и API, но не гарантирует, что откроются приложения: она отправляет обычные HTTPS-запросы и не видит проблем, которые зависят от того, как именно работает приложение.

## Обновление

При запуске приложение один раз запрашивает у GitHub последний релиз этого репозитория. Если вышла новая версия, внизу окна появится **Обновить и перезапустить**. По нажатию приложение:

1. скачивает `Nimb-<версия>.zip` из релиза;
2. сверяет SHA-256 с тем, что указан в описании релиза, и проверяет, что внутри именно Nimb нужной версии с целой подписью;
3. закрывается, заменяет приложение на месте и открывает новую версию. Если оно называлось `RDNS.app`, новое ставится рядом как `Nimb.app`, а старое убирается.

Если проверка не прошла, ничего не заменяется. Хэш лежит в том же релизе, что и файл: это защита от повреждённой загрузки, но не от взлома самого репозитория. Заменить приложение можно, только если оно лежит в папке, куда у вас есть доступ на запись (например, «Программы»); приложение, запущенное прямо из загрузок, сначала переместите. Сборку из исходников обновление не делает: оно ставит готовую сборку из релиза.

## Переключение без пароля

По умолчанию macOS спрашивает пароль администратора (или Touch ID, если он настроен) при каждом включении и выключении: это требование системы для смены DNS. Если это мешает, откройте **Настройки** (шестерёнка в правом верхнем углу) → **Смена DNS без пароля**. Кнопка **Дать** (после предупреждения о риске и одного ввода пароля) кладёт в `/etc/sudoers.d/nimb` правило для вашей учётной записи:

```
<пользователь> ALL = (root) NOPASSWD: /usr/sbin/networksetup -setdnsservers *, /usr/bin/dscacheutil -flushcache, /usr/bin/killall -HUP mDNSResponder
```

Правило разрешает только эти три команды, а не полный доступ к системе; перед установкой оно проверяется `visudo`. Цена: любая программа, запущенная от вашего имени, тоже сможет менять DNS на этом Mac без пароля, например чтобы направлять сайты на чужие серверы. Кнопка **Забрать** удаляет файл целиком (потребуется пароль). Вручную: `sudo rm /etc/sudoers.d/nimb`.

## Настройки и удаление

В **Настройках** собраны разрешения Nimb: смена DNS без пароля (см. выше) и проверка обновлений при запуске (один запрос к GitHub; можно забрать, кнопка проверки внизу окна работает в любом случае). Больше Nimb ничего не просит.

Кнопка **Удалить Nimb** сначала возвращает DNS к автоматическому (только на тех подключениях, где стоит один из сервисов Nimb; DNS, заданный вами вручную, не трогается) и удаляет правило «без пароля» (один ввод пароля администратора), затем закрывает приложение, и оно удаляет само себя: `Nimb.app` (и старый `RDNS.app`, если он лежит рядом или в «Программах»), настройки, кэш, сохранённое состояние окна и недокачанные обновления. Если у приложения нет права записи в его папку, удаление не начнётся.

## Как это работает

Приложение вызывает стандартные команды macOS и больше ничего не делает:

```sh
networksetup -setdnsservers "<сервис>" 83.220.169.155 212.109.195.93   # включить
networksetup -setdnsservers "<сервис>" Empty                           # выключить
dscacheutil -flushcache; killall -HUP mDNSResponder                    # сбросить кэш
```

DNS меняется на всех включённых сетевых сервисах с физическим адаптером (Wi-Fi, Ethernet). VPN-подключения не затрагиваются.

## Сборка

Нужны Xcode или Command Line Tools (Swift 5.9+), macOS 13+.

```sh
./scripts/build_app.sh
open build/Nimb.app
```

Результат: `build/Nimb.app` (universal: Apple Silicon + Intel, подпись ad-hoc). Для релиза: `LEGACY=1 ./scripts/build_app.sh` собирает ещё и `build/RDNS.app` (то же приложение под старым именем и идентификатором) для обновления установок, сделанных до переименования.

## Важно

- Проект не связан с Comss.one и GeoHide. Это бесплатные сервисы, доступ через них может пропасть в любой момент: если сайт не открывается, переключитесь на другой.
- Если на Mac включён VPN, DNS-профиль (Системные настройки → Сеть → VPN и фильтры → «Фильтры и прокси») или локальный DNS-прокси, они могут использовать свой DNS и перекрывать настройки приложения. В этом случае Nimb покажет предупреждение под списком сервисов.
- Пользуйтесь сервисами по их правилам. Всё, что вы делаете с программой, вы делаете на свой риск.

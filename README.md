# RDNS

Smart DNS одной кнопкой для macOS. Включает DNS-сервис (Comss.one, GeoHide, GeoHide EU) на всех сетевых подключениях Mac, а при выключении возвращает DNS от роутера или провайдера. Это не VPN: через сервис идут только DNS-запросы, остальной трафик идёт напрямую.

Идея и принцип работы взяты у [hb-ai-xbox-dns](https://github.com/neiroseti-ai/hb-ai-xbox-dns) для Windows. Код написан с нуля на Swift/SwiftUI.

## Как пользоваться

1. Соберите приложение (см. ниже) или скачайте `RDNS.app` из Releases.
2. Откройте `RDNS.app`. Приложение без подписи Apple Developer, поэтому при первом запуске: правый клик → **Открыть** → **Открыть** (или Системные настройки → Конфиденциальность и безопасность → **Всё равно открыть**).
3. Выберите сервис и нажмите большую кнопку. macOS запросит пароль администратора: без него DNS менять нельзя.
4. Нажмите ещё раз, чтобы вернуть автоматический DNS.

## Как это работает

Приложение вызывает стандартные команды macOS и больше ничего не делает:

```sh
networksetup -setdnsservers "<сервис>" 83.220.169.155 212.109.195.93   # включить
networksetup -setdnsservers "<сервис>" Empty                           # выключить
dscacheutil -flushcache; killall -HUP mDNSResponder                    # сбросить кэш
```

DNS меняется на всех включённых сетевых сервисах с физическим адаптером (Wi-Fi, Ethernet). VPN-подключения не затрагиваются.

## Сборка

Нужны Xcode или Command Line Tools (Swift 5.9+), macOS 13+.

```sh
./scripts/build_app.sh
open build/RDNS.app
```

Результат: `build/RDNS.app` (universal: Apple Silicon + Intel, подпись ad-hoc).

## Важно

- Проект не связан с Comss.one и GeoHide. Это бесплатные сервисы, доступ через них может пропасть в любой момент: если сайт не открывается, переключитесь на другой.
- Если на Mac включён VPN, DNS-профиль (Системные настройки → Сеть → VPN и фильтры → «Фильтры и прокси») или локальный DNS-прокси, они могут использовать свой DNS и перекрывать настройки приложения. В этом случае RDNS покажет предупреждение под списком сервисов.
- Пользуйтесь сервисами по их правилам. Всё, что вы делаете с программой, вы делаете на свой риск.

# Сторонние компоненты Nimb для Windows

Лицензии полных текстов лежат в исходниках этих проектов. Всё ниже можно использовать бесплатно и распространять вместе с программой.

| Компонент | Для чего | Лицензия |
|---|---|---|
| [amneziawg-go](https://github.com/amnezia-vpn/amneziawg-go) (v3.1.20260828) | туннель AmneziaWG как библиотека | MIT |
| [wintun](https://www.wintun.net/) (0.14.1, `wintun.dll`) | сетевой адаптер туннеля | «Prebuilt Binaries License» (разрешено поставлять `wintun.dll` с программой, менять DLL нельзя) |
| [wireguard-windows](https://git.zx2c4.com/wireguard-windows) (пакет `tunnel/winipcfg`) | адреса, маршруты и DNS адаптера | MIT |
| [Wails](https://wails.io) v2.17.0 | окно (WebView2) | MIT |
| [fyne.io/systray](https://github.com/fyne-io/systray) | значок у часов | Apache-2.0 |
| [go-winio](https://github.com/microsoft/go-winio) | закрытый канал службы | MIT |
| golang.org/x/sys, x/crypto, x/net | системные вызовы Windows | BSD-3-Clause |
| [TG WS Proxy](https://github.com/Flowseal/tg-ws-proxy) (Flowseal) | образец прокси Telegram, порт на Go | MIT |
| [Inter](https://rsms.me/inter/) и [Source Serif 4](https://github.com/adobe-fonts/source-serif) | шрифты окна (лежат в `fonts/` рядом с лицензиями) | SIL OFL 1.1 |
| Microsoft Edge WebView2 Runtime | отображение окна | входит в Windows 11, на Windows 10 ставится отдельно |

Картинки и анимации сделаны для Nimb заново, см. `art-studio/deliver/CREDITS.md`.

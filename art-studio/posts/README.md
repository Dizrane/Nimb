# Изображения к постам Nimb

## Утверждённый образец: Mac Glass v2

Для будущих изображений к постам об обновлении используй этот образец как исходное направление.

- Готовое изображение: [Mac Glass v2](nimb-0.9.26-windows-0.4.2-mac-glass-v2.png), 1672 × 941 px, PNG, горизонтальная композиция примерно 16:9.
- Точный промпт: [mac-glass-v2-prompt.md](nimb-0.9.26-windows-0.4.2-mac-glass-v2-prompt.md).
- Первоначальный референс пользователя: [initial-composition.jpg](references/initial-composition.jpg). Он нужен только для истории композиции; версии и Windows-интерфейс из него не переносить. Утверждённый v2 имеет приоритет.
- Инструмент: встроенный ImageGen. При создании v2 использованы два изображения: снимок установленного Nimb 0.9.26 для macOS и первоначальный композиционный референс. Состояние «всё включено» в иллюстрации поставлено художественно; реальные сетевые функции ради снимка не включались.

## Что сохранять в следующих постах

- Главный объект — окно **Mac-версии**, а не Windows: три круглые кнопки слева сверху, реальные пропорции, боковая панель, шрифты и графика Nimb.
- Одно большое окно парит в перспективе: левый край ближе, правый немного дальше; ориентир — поворот около 20° и небольшой наклон. Окно целиком видно, вокруг достаточно свободного места.
- Палитра — чёрный, графитовый и серебристо-белый. Зелёный допустим в переключателях самого приложения.
- Фон — почти чёрный, с редкими мелкими звёздами. Свет мягкий и сдержанный.
- Позади окна — тонкая пластина дымчатого стекла. В v2 на её внешнем углу несколько тонких трещин; само окно целое, интерфейс ими не перекрывается.
- Надписи только внутри интерфейса. Не добавлять заголовок поста, перечень изменений, версии снаружи окна, стрелки или отдельные рекламные значки.
- Не возвращаться к отдельному глобусу, щиту, самолётику и сетевым орбитам: утверждённый вариант построен вокруг приложения.

## Как воспроизвести

1. Для абсолютно того же результата используй сохранённый PNG: это оригинальный утверждённый файл. Генерация не гарантирует побайтового повторения.
2. Для нового выпуска получи свежий снимок **Mac-версии** через разрешённый инструмент работы с интерфейсом. Сними главный экран, убери из кадра личные данные. Сервисы и сетевые настройки ради картинки не переключать; активное состояние при необходимости можно поставить в иллюстрации.
3. Передай ImageGen два референса с явными ролями: свежий снимок Mac — источник интерфейса; утверждённый Mac Glass v2 — источник композиции, материалов и света. Первоначальный пример пользователя использовать только при необходимости как дополнительный референс.
4. Возьми сохранённый промпт. Замени старую версию Mac на новую и уточни роли входных изображений: во втором входе теперь утверждённый v2, а не первоначальный пример. Сохрани художественные ограничения. Не заменяй macOS-интерфейс Windows-интерфейсом даже для совместного поста.
5. Выведи один горизонтальный вариант без внешнего текста. Если приложение заметно изменилось, сохраняй актуальный интерфейс, а не устаревшие элементы эталона.
6. Проверь: Mac-кнопки слева, правдоподобная перспектива, правильная версия, читаемые подписи, отсутствие выдуманных элементов, целое окно, тонкое стекло, редкие звёзды, отсутствие лишнего текста.
7. Сохрани новый вариант и его точный промпт отдельными файлами. Утверждённый PNG и промпт v2 не перезаписывай. После одобрения нового варианта обнови ссылку на эталон здесь.

При редактировании локальных референсов сначала просмотри изображения. Выбирай механизм передачи изображений согласно доступному ImageGen: локальные пути, когда все входы имеют пути; иначе — минимальное число последних изображений, включающее все нужные входы. Оба механизма одновременно не использовать.

# Студия графики Nimb

Здесь делаются картинки, анимации и модельки для приложения: нимбы, пёсик Telegram, самолётик, новая анимация для YouTube и Discord. Это отдельное рабочее место: приложение отсюда не собирается и не меняется.

## Как начать

```bash
cd art-studio
claude
```

Больше ничего писать не нужно. Claude Code прочитает `CLAUDE.md` в этой папке и сам начнёт: изучит приложение, предложит план, покажет первые варианты. Ему дана полная творческая свобода: как выглядит и как двигается, решает он. Вы выбираете из вариантов и говорите, что нравится, а что нет.

Первое, что стоит сделать вам: положить в `references/` то, чего там нет:
- ваш оригинальный рисунок пёсика с прозрачным фоном (сейчас там только версия из приложения с закрашенным лицом);
- картинку-референс сияющего нимба, которую вы показывали: «как физическое сияющее кольцо».

## Что внутри

| Папка | Для чего |
|---|---|
| `CLAUDE.md` | Задание и правила работы для Claude Code в этой папке |
| `brief/` | Описание проекта, стиль, технические ограничения, формат сдачи ресурсов, как мы работаем вместе |
| `references/` | Что нужно знать о текущем виде: ваши рисунки, значок приложения, ссылки на код отрисовки |
| `tools/` | Просмотрщик, который показывает ресурсы на фоне и в размере окна Nimb |
| `work/` | Черновики и исходники (в git не попадает) |
| `previews/` | Промежуточные результаты для вас, по папке на каждый шаг (в git не попадает) |
| `deliver/` | Готовые ресурсы для приложения, по папке на каждый, с `manifest.json` |

## Как отдать готовое приложению

Когда ресурс готов и вам нравится, откройте основной чат (в корне проекта) и вставьте то, что написано в `HANDOFF.md`: он знает, как принять и подключить готовое. Приложение читает ресурсы из `deliver/` по `manifest.json`, поэтому ничего вручную переносить не нужно.

## Правила

- Всё должно быть оригинальным или с понятной лицензией, источники записываются в `deliver/CREDITS.md`. Проект распространяется по PolyForm Noncommercial.
- В ресурсах не должно быть личных данных (ни вашего имени, ни путей).
- Тяжёлое не страшно, пока бюджет соблюдён (см. `brief/ASSET_CONTRACT.md`): окно рисуется, только когда его видно.

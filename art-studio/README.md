# Графика Nimb

- `deliver/` — готовая графика, которую рисуют приложения (Mac берёт её при сборке `scripts/build_app.sh`, Windows держит копию в `windows/cmd/nimb/frontend/dist/art`). В каждой папке есть `manifest.json`; лицензии и источники в `deliver/CREDITS.md`.
- `work/` — скрипты, из которых получается часть графики (значки, нимб, пёсик Telegram). Нужны, чтобы перерисовать ресурс.
- `previews/` — промежуточные картинки, в git не попадают.

Новое изображение кладётся в `deliver/<имя>/`, у Windows копия обновляется отдельно. В ресурсах не должно быть личных данных (ни имён, ни путей).

# Контракт ресурсов: как сдавать готовое

Готовое кладётся в `deliver/<имя>/`. Приложение читает `manifest.json` и по нему подключает файлы, поэтому формат ниже нужно соблюдать. Если нужно что-то, чего здесь нет (другой формат, свои поля), **добавь это в манифест в поле `notes` и скажи пользователю**: подключать будет другой чат, и ему нужно понимать, как это двигать.

## Что приложению нужно (набор ресурсов)

| Имя | Что это |
|---|---|
| `halo` | Нимб: задняя и передняя половины (обязательно раздельно), слои свечения и лучей, искры, плюс как он дышит и крутится |
| `halo-small` | Маленький нимб над значком шага обучения (можно получить из `halo`, если масштабируется без потерь) |
| `hood` | Пёсик: состояния «выключен» и «включён», живая петля |
| `paper-plane` | Бумажный самолётик: модель и анимация полёта по дуге, след, наклон |
| `media-motion` | Новая анимация для YouTube и Discord вместо спутника |
| `media-screen` | Экран с play и значок Discord (если решишь перерисовать сцену) |
| `app-icon` | (позже) значок приложения с новым нимбом |

Планету и спутник не делай: они остаются как есть.

## Общие правила

- **Размеры в пунктах, файлы в пикселях ×2.** Сцена страницы около 360×218 пунктов, поэтому делай запас под свечение и лучи. Нимб сейчас занимает холст 336×194 пунктов (672×388 пикселей), центр кольца в центре холста, горизонтальные лучи выходят за кольцо примерно на его ширину. Можно больше, но пиши размеры в манифесте.
- **Фон: прозрачный.** Картинки PNG с прозрачностью (проверь на чёрном: светлой каймы по краям быть не должно). Для свечений укажи `"blend": "screen"` (добавляется к фону): тогда они хорошо ложатся на чёрное.
- **Форматы.** Картинки: PNG (WebP не используй, на macOS 13 он не открывается). Короткая анимация: либо последовательность PNG, либо `.mov` с HEVC и прозрачностью (`hevc_videotoolbox` в ffmpeg умеет альфа-канал; проверь на чёрном). Модели 3D (USDZ) только по согласованию с пользователем и если без них нельзя.
- **Цвет.** Нимб и фигуры нейтральные. Цвет только у статусных элементов (зелёный луч).
- **Бюджет.** На одну страницу в сумме не больше **3 МБ** файлов и не больше **40 МБ** распакованных в память (ширина × высота × 4 байта × число кадров). Петли 12–24 кадра в секунду, до 4 секунд. Всё вместе не больше 12 МБ. Приложение загружает ресурсы страницы при открытии окна и выгружает при закрытии, но лишнее всё равно ни к чему.
- **Загрузка при пустом экране.** Первый кадр должен выглядеть хорошо и без анимации (если пользователь выбрал «уменьшить движение», вместо движения будет первый кадр).
- **Имена.** Строчные латинские буквы, цифры и дефис. Без пробелов.
- **Метаданные.** Очисти EXIF/XMP и пути из файлов.

## manifest.json

```json
{
  "name": "halo",
  "version": 1,
  "scale": 2,
  "pointSize": [336, 194],
  "layers": [
    { "id": "back",  "file": "back.png",  "role": "behind-figure", "blend": "normal" },
    { "id": "front", "file": "front.png", "role": "in-front-of-figure", "blend": "normal" },
    { "id": "bloom", "file": "bloom.png", "role": "in-front-of-figure", "blend": "screen", "opacity": 0.8 }
  ],
  "loops": [
    { "id": "shimmer", "file": "shimmer.mov", "kind": "hevc-alpha", "fps": 24, "seconds": 4,
      "role": "in-front-of-figure", "blend": "screen" }
  ],
  "anchors": {
    "center": [168, 97],
    "crown": [168, 97]
  },
  "motion": [
    { "target": "all", "type": "breathe", "period": 5.0, "amount": 0.04, "notes": "opacity and scale" },
    { "target": "all", "type": "drop-in", "from": [0, -18], "seconds": 1.0 }
  ],
  "states": {
    "off": { "visible": false },
    "on": { "visible": true },
    "busy": { "speed": 2.0 }
  },
  "notes": "Что важно знать тому, кто это подключает."
}
```

Правила манифеста:
- `layers` и `loops` перечисляются **снизу вверх** в порядке рисования внутри своей роли. Роли: `behind-figure` (до фигуры), `in-front-of-figure` (после фигуры).
- `anchors`: все точки в пунктах от верхнего левого угла холста. Для нимба важна `crown` (куда он садится на макушку фигуры). Для пёсика нужны `crown`, `nose` (куда бьёт луч), `center`. Для самолётика `nose` и `tail` (откуда след).
- `motion` описывает, как двигать слои: `breathe` (дыхание), `float` (парение), `spin` (поворот), `drop-in` (появление сверху), `sway` (покачивание). Если нужно что-то другое, опиши словами в `notes`, и тот, кто подключает, реализует.
- `states` задаёт, что показывать в «выключено / включается / включено / занято».

## Проверка перед сдачей

1. Открыть в `tools/stage.html` на чёрном фоне (`tools/serve.sh`) и убедиться, что в четырёх состояниях всё выглядит хорошо.
2. Проверить края прозрачности на чёрном (нет светлой каймы).
3. Посчитать размер файлов и память, записать в `notes`.
4. Записать источники и инструменты в `deliver/CREDITS.md`.

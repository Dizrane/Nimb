# Источники и инструменты

Всё в этой папке сделано заново в студии графики Nimb, внешних картинок, моделей и шрифтов нет.

| Ресурс | Как сделан |
|---|---|
| `halo/` | Свой рендер (Python 3, numpy, стандартная библиотека): свет считается в линейном виде, объектив как сумма гауссиан, лучи как зум-размытие, сжатие `1 - exp(-x)`. Цель по нимбу (`references/goal.jpg.avif`) использовалась только как образец для сравнения, из неё ничего не взято. |
| `hood/` | Свой рендер (Python 3, numpy). Формы капюшона, мордочки и носа взяты из рисунка пользователя (`references/dog-from-app-filled-face.png`), очищены и скруглены, свет добавлен кодом. |
| `paper-plane/` | Своя 3D-модель из шести граней и свой растеризатор (Python 3, numpy). Модель полёта `wander.js` написана здесь же. |
| `media-scene/` | Свой рендер (Python 3, numpy). Формы экрана, кнопки play и значка Discord взяты из текущего рисунка приложения (`Sources/Nimb/ScreenArt.swift`), заново отрисованы с новым светом. Форма значка Discord это уже существующий рисунок проекта; если нужен более оригинальный значок, это отдельное решение. |
| `media-motion/` | Своя анимация (JavaScript, canvas 2D), без внешних материалов. |

Лицензия: проект распространяется по PolyForm Noncommercial; ресурсы созданы специально для него.
В файлах нет метаданных (EXIF/XMP), имён и путей.

# Передача готового в приложение

Скопируйте это в основной чат Claude Code (в корне проекта Nimb), подставив названия:

```
В art-studio/deliver/ лежат готовые ресурсы: <halo>, <hood>, <paper-plane>, <media-motion>.
Прими и подключи их в приложение по manifest.json каждого: замени ими текущую
отрисовку нимбов (главная, Telegram, YouTube и Discord, обучение), пёсика,
самолётик, и убери спутник на странице YouTube и Discord в пользу новой анимации.
Проверь, что нагрузка не выросла (окно в фокусе до 10 % процессора, закрытое 0 %),
что оформление чёрно-белое и цвет только у статусов, и покажи скриншоты страниц.
Релиз не делай, пока я не скажу.
```

Если нужна только часть (например, только нимб), так и напишите.
